# Local Photo Frame · 局域网电子相框

把闲置电脑、Windows 平板变成电子相册：手机打开中文管理页上传照片，设备从本地磁盘读取原图并全屏轮播。无需 NAS、云相册或独立服务器，照片就保存在运行相框的电脑上。

## 功能

| 功能 | 说明 |
| --- | --- |
| 手机管理 | 中文 H5 页面，支持多图上传、上传进度、成功及失败提醒、失败重试 |
| 原图保存 | 默认不压缩；可选缩小上传图片，原图播放不经过缩略图接口 |
| 照片管理 | 缩略图网格、每页 24 张、搜索、排序、大图预览、跨页勾选与批量删除 |
| 可恢复删除 | 照片移到本地 `recycle/`，不会直接永久删除 |
| 全屏播放 | 横图单独展示，竖图通常组合 2–3 张，按屏幕和图片比例分组 |
| 随机组合 | 每轮重新打乱竖图搭配，并尽量避免上一轮的相同组合 |
| 随机转场 | 淡入淡出、横向移动、纵向移动、缩放，避免连续相同效果 |
| 自动同步 | 约每 2 秒检查照片列表，每次切换前再次核对；删除当前照片时清除旧画面与转场 |
| 低开销尺寸读取 | 服务端读取并缓存图片头信息，处理 EXIF 方向，无需为读取尺寸而解码每张原图 |
| Windows 兼容息屏 | 管理页切换黑屏和恢复播放；保持联网，支持触碰或按键恢复 |

铺满使用等比裁切，照片不会拉伸；不同宽高比下仍可能裁掉部分边缘。竖图组合能减轻裁切，但不能保证所有构图都完整显示。只有一张竖图时同样会裁切铺满。

## 环境

- Python **3.13 或更高**，推荐 64 位；安装 Python 时启用 pip。
- 现代浏览器，如 Edge、Chrome、Safari；播放页使用 Web Animations、图片解码与请求超时接口。
- Node.js 20 或更高仅用于开发测试，正常使用不需要。
- 相册和手机管理可在 Windows、macOS、Linux 上运行。
- 背光及兼容息屏仅支持具备相应 WMI 接口的 Windows 设备；其他系统不影响上传和播放，但屏幕控制不可用。

## 快速开始

下载仓库 ZIP 并解压，或克隆仓库。在项目目录运行：

### Windows（PowerShell）

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe server.py --host 0.0.0.0 --port 4444
```

如果安装的是更新的 Python，请把 `py -3.13` 改成对应版本。

### macOS / Linux

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py --host 0.0.0.0 --port 4444
```

设备本机打开：

- 播放页：<http://localhost:4444/>
- 管理页：<http://localhost:4444/upload>

手机连接同一个局域网，在浏览器输入 `http://<相框设备的局域网地址>:4444/upload`。设备地址请从运行相框的电脑网络设置中查看。Windows 防火墙如有提示，仅允许可信的专用网络；需要允许该端口时，也应将来源限制到本地子网。

**使用范围：** 当前版本没有登录鉴权，同一网络内能够连接服务的人可以查看照片、上传、删除和操作屏幕。请仅在可信局域网使用，不要配置公网端口转发。只想在本机使用时，省略 `--host 0.0.0.0`，默认只监听本机。

使用 Waitress 提供服务，不使用 Flask 调试服务器。

## 手机上传与管理

1. 打开管理页，点“选择手机照片”，可以一次选择多张。
2. 默认勾选“原图上传，不压缩”，再点“上传”。
3. 上传过程中有逐张进度；完成后显示成功张数，失败的照片保留以便重试。
4. 下方缩略图可点开预览，勾选左上角可跨页选择；点击“删除所选”并确认后移入回收目录。
5. 播放列表会自动更新，无需重启相框。网络正常、页面活跃时通常约 2 秒检测到变化；新图实际显示还受当前轮播位置和加载时间影响。

支持 JPG / JPEG / PNG / GIF。单张文件限制为 50 MB；HEIC / HEIF 需先导出为 JPG 或 PNG。动画 GIF 的实际播放效果由浏览器决定。

网页的“原图”选项表示服务端不重新编码收到的文件。手机相册、分享面板或应用内浏览器仍可能在选取文件前压缩或转换；需要保留原始文件时，请在手机端也选原图或通过文件选择器上传。

## 全屏播放与开机启动

在浏览器打开播放页后按 F11。Windows Edge 也可用全屏 kiosk 模式，先确认 Edge 安装路径，再在 PowerShell 运行：

```powershell
$edge = Join-Path ${env:ProgramFiles(x86)} 'Microsoft\Edge\Application\msedge.exe'
& $edge --kiosk http://localhost:4444 --edge-kiosk-type=fullscreen --no-first-run
```

若找不到 Edge，请使用自己的实际安装路径。kiosk 模式可用 Alt+F4 退出。

需要开机后自动播放时，可在 Windows“任务计划程序”创建“用户登录时”任务：程序选择项目 `.venv\Scripts\pythonw.exe`，参数填 `server.py --host 0.0.0.0 --port 4444`，起始位置填项目目录。使用“仅当用户登录时运行”，屏幕控制需要位于登录用户的交互桌面中。另建延迟启动浏览器的任务。项目不保存 Windows 密码，也不会修改系统自动登录设置。

在“播放设置”中可以调整每张停留时间和压缩上传的最大宽高。设置约 30 秒内自动应用；列表同步固定为约 2 秒。兼容旧配置的 `refreshImages` 和 `rotateImages` 字段仍保留在后端，但公开管理页不展示未生效的旋转或同步间隔选项。

## Windows 息屏与亮屏

某些旧 Windows 平板在真正关闭显示器时会进入现代待机并断开 Wi-Fi，手机就无法远程开屏。本项目使用兼容方式：

- 息屏时覆盖原生全屏纯黑窗口，把背光降到设备支持的最低档，保持系统和网络运行。
- 关闭息屏开关、点击“立即亮屏”，或触碰 / 点击黑色窗口、按键，可恢复照片。
- 恢复时还原先前的背光与自适应亮度配置；服务异常退出后的下一次启动也会尝试恢复。
- **这不是显示器物理断电，也不是系统睡眠或锁屏，不能保证零背光或特定省电幅度。** 系统电源键、休眠和断网后的远程唤醒不属于此开关的能力。

背光控制通过 Windows WMI 和 `powercfg` 完成，需要设备支持并具备修改权限；失败时页面会报错。模块仅为自带 PowerShell 脚本的单次进程指定执行参数，不修改全局执行策略。首次在其他设备使用时，建议现场验证并保留物理触碰恢复能力。

不会安装或控制远程桌面软件，也不包含系统清理、卸载软件、修改账户或关闭安全功能的脚本。

## 文件与备份

| 路径 | 内容 |
| --- | --- |
| `images/` | 上传的照片原文件 |
| `thumbnails/` | 按需生成的缩略图缓存，可删除后重建 |
| `recycle/` | 删除照片的可恢复副本，文件名前会增加时间戳 |
| `settings.txt` | 本机播放与上传设置 |
| `display-backlight-state.json` | 息屏期间临时保存的本机背光状态 |

首次运行自动创建照片目录，不附带任何示例照片或真实照片截图。以上运行数据均已加入 `.gitignore`，本仓库不包含设备账号、密码、私有网络地址或本机绝对路径。

备份时停止服务，再复制 `images/`、`recycle/` 和 `settings.txt`。恢复误删照片时，把对应文件从 `recycle/` 移回 `images/`，使用唯一文件名并保留扩展名；列表会自动同步。回收目录不会自动清空，请按需自行整理磁盘空间。

## 开发与验证

```sh
python -m pip install -r requirements-dev.txt
python -m pytest -q
node --test test_playlist.cjs
```

测试图片由测试运行时生成，不需要个人照片。覆盖原图字节保留、EXIF 方向、缩略图缓存、上传失败、回收删除、路径校验、设置校验、屏幕控制结果反馈和播放列表增删同步。Windows 背光硬件行为不在跨平台自动化测试范围内。

主要代码：`app.py`（接口与本地文件管理）、`templates/upload.html`（手机管理页）、`templates/gallery.html`（播放页）、`display_control.py` / `display-backlight.ps1`（Windows 兼容息屏）、`server.py`（服务入口）。
